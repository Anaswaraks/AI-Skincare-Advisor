# AI Skincare Advisor

## Project Overview

An AI-powered skincare advisory application
that helps users explore skincare products based
on their preferences, concerns, ingredients and budget.

## Main Objectives

1. Build a skincare product recommendation system.
2. Analyse customer reviews using NLP.
3. Compare traditional ML and transformer models.
4. Build an ingredient knowledge base.
5. Implement RAG-based question answering.
6. Integrate LLM tool calling.
7. Develop APIs using FastAPI.
8. Deploy the application.

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- PyTorch
- Hugging Face
- ChromaDB
- FastAPI
- Streamlit
- Docker
